# 2026-10-31

## 输入卡（Composer）液态玻璃返工

用户反馈四条：两端玻璃渲染差、卡内组件不统一、没有液态圆滑边框、上界没固定 +
「回到底部」按钮会随上界拖动漂移。

### 根因（实测，不是猜）
1. `backdrop-filter:url(#cmp-glass-ref)`（SVG feImage+feDisplacementMap 折射）
   在 Chromium/WebView2 上 **CSS.supports() 返回 true 但渲染时整条滤镜被丢弃**：
   卡片既没模糊也没折射，背后文字原样透上来盖住占位符 → 看着像"上界没固定"；
   位移贴图还在两端留下硬缝 → "两端没渲染好"。
2. `#composerInner:focus-within{box-shadow:none}` 把唯一的边界（box-shadow）
   在聚焦瞬间全部撤掉 → 一边输入一边"消失的上界"。
3. `Layout.set('composer')` 上限是 `innerHeight-200`，但 CSS 是 `max-height:72vh`：
   拖过 72vh 后卡片停住、`--composer-h` 继续涨 → 手柄脱节，
   `.jump-bottom` 用 `--composer-h` 推算位置，于是飘到卡片里面（实测差 99px）。
4. 卡内控件各写各的 rgba 渐变，发送钮是实心 accent 圆饼 → 不成一族材质。

### 改法
- 彻底删掉 SVG 折射路径（JS 的 glassSDF/paintGlassMap/ensureGlassFilter/
  setupGlassRefraction 全删），只留 `backdrop-filter:blur(var(--cmp-glass-blur)) saturate(1.12)`。
- 00-tokens.css 新增 `--glass-face/-hover/-on`、`--glass-line(-hover)`、
  `--glass-hi/-lo/-drop`、`--glass-blur`：卡片内所有控件（+ / chip / 发送 /
  附件 chip / 回到底部）共用这一族。
- 卡片边缘：`::before` 1.25px **conic** 渐变环（左上最亮、右下最暗，最低 .13 不断线）
  + box-shadow 均匀内环 + 8px 沿边柔光 + 顶部镜面 + 底回光。聚焦只提亮不撤环。
- `Layout.composerH()` 成为**唯一**写 `--composer-h` 的地方，上限夹到 72vh（与 CSS 同值）。
- `02-render2-chat.js`：`placeJump()` 用卡片**实测**矩形定位按钮（pane 相对 bottom），
  `syncJumpAnchors()` 同时写 `--composer-pad` 给 `.chat` 底部留白
  （Teamwork 模式卡片 64vh，变量推算会把消息压在卡片下）。
- 发送钮改成"掺 accent 的玻璃"；`.stop` 只染描边不填红。

### 验收脚本（可复用）
`_scratch/composer-glass-2026-10-31/verify3.py`（两端/上界/拖拽/空态）、
`verify4.py`（聚焦/Teamwork/旧存储超限）、`zoom4.py`（4x 看两端）、
`t-filter.py`（探测 backdrop-filter:url 是否真生效）。
关键断言：卡片上界与 jump 按钮 gap 恒为 16px；`--composer-h` == 卡片实测高。

## 追加：按 shuding/liquid-glass 复刻真实折射（同日晚）

### 推翻上一条的错误结论
上一条写「Chromium 不支持 backdrop-filter:url()」——**错了**。真相是：
`<filter>` 用默认的 `filterUnits=objectBoundingBox` + `width="100%"` 时，
Chromium 会把整条滤镜吞掉（既不模糊也不折射）。改成
`filterUnits="userSpaceOnUse"` + **像素** x/y/width/height 就正常工作。
最小复现：`_scratch/composer-glass-2026-10-31/t-lens2.py`（两组盒子对照，
url+feGaussianBlur 能模糊、url+feDisplacementMap 能折射）。

### 现在的实现（= 参考管线）
- `js/05-composer.js`：`LENS` / `lensSVG()` / `lensSDF()` / `paintLens()` /
  `syncLens()` / `scheduleLens()` / `setupLens()`。canvas 逐像素算圆角矩形 SDF
  → 贴边沿内法线反向采样（放大）→ R/G 位移贴图 → feImage + feDisplacementMap。
  band = 短边×0.12（10–24px），strength 0.9；大卡片按 1/2 分辨率算（重绘 4ms）。
- `css/05b-composer.css`：基类纯 blur（降级），`.glass-lens` 才挂
  `backdrop-filter:url(#cmp-lens) blur(var(--cmp-glass-blur)) contrast(1.2) brightness(1.05) saturate(1.1)`
  ——滤镜元素由 JS 创建，先引用会让整条声明失效、首帧变透明，所以用类切换。
- 偏好键换成 `cell.glass.v2`，默认 t=0.4（≈5px），0% = 完全通透只剩折射。
- 卡片上内边距 20px：折射带约 19px，文字压在带内会被"从下面拉上来"的
  背后内容糊住（第一版 16px 时占位符和鬼影叠在一起）。

### 验证脚本
`t-lens2.py`（管线最小复现）、`lens-probe.py <磨砂%>`（把高对比条纹背景塞到卡片
背后，4x 看折射）、`verify3/verify4/zoom4` 全部仍通过。
